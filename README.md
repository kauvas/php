### About
I got into tech fascinated by problem-solving and software architecture. I earned my Bachelor's Degree in Systems Analysis and Development at Uniube, building a solid foundation in software engineering, database design, and end-to-end web development.

Throughout my journey, I specialized in Full Stack Web Development—building robust MVC applications, secure authentication systems, and dynamic front-end interfaces. Additionally, I expanded into Data Engineering, designing end-to-end ETL pipelines, optimizing relational databases, and delivering business intelligence dashboards.

My approach combines clean code practices, analytical thinking, and agile management. Whether building web platforms or data pipelines, I focus on creating scalable, efficient, and well-structured software solutions.
